# Reclaim-It

## Overview

Reclaim-It is a community-driven lost and found platform that helps users report, search, and recover misplaced items quickly and securely. The platform enables owners and finders to connect safely and efficiently.

## Features

* Report lost items
* Report found items
* Browse listings
* User authentication
* Manage personal reports
* Responsive user interface

## Technologies Used

* React
* TypeScript
* Vite
* Supabase
* CSS

## Installation

1. Clone the repository

git clone https://github.com/prasanna-657/Reclaim-It.git

2. Navigate to the project folder

cd Reclaim-It

3. Install dependencies

npm install

4. Start the development server

npm run dev

5. Open in browser

http://localhost:8080
